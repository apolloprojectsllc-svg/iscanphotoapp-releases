# iScanPhotoApp downloads

Installers for **iScanPhotoApp**, the family photo organizer for Windows 10 and 11 by
Apollo Projects LLC. It finds the faces in your photos, asks who they are, and lets you find
every photo of everyone you love. It runs on your own PC: no account, no cloud, and your
original photos are never changed.

- Website, help and support: https://iscanphoto.com
- Questions: support@iscanphoto.com

Download the latest version from **[Releases](../../releases)**. This repository holds
installers only; there is no source code here.
